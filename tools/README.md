# Генератор демо-сайтів

Кожне демо — папка `<slug>/` з `index.html` і `og-image.png`, опублікована на
`https://balanykb-dh.github.io/demos/<slug>/`.

## Як додати бізнес

1. Перевір картку в Google Maps: назва, адреса, телефон, графік, рейтинг, кількість відгуків, чи немає сайту.
2. Додай словник у `sites.py` (зразок — будь-який наявний). Тема ніші: `asphalt` (авто), `velvet` (меблі, текстиль), `tape` (ательє) або нова в `themes.py`.
3. Збери: `python3 tools/build.py <slug>` (потрібні `jinja2` і `playwright` для прев'ю-картинки).
4. Перевір сторінку на ширині 320–1366 px з реальними шрифтами, зроби два скриншоти для повідомлення.

## Правила

- Тільки факти з Google Maps і того, що пишуть у відгуках. Без вигаданих відгуків і цін.
- Смуга «Демо-концепт» і `noindex` лишаються, поки власник не погодився.
- Якщо власник відмовив або мовчить понад 3 тижні, папку видаляємо.
